# Diagrams (Mermaid) – Rendering Hinweise

- Schriftgröße: Mindestens 11pt auf A4. In allen .mmd-Dateien ist `%%{init: {'themeVariables': { 'fontSize': '15px'}}}%%` gesetzt, was einer typischen Darstellungsgröße >= 11pt entspricht.
- Rendering: Verwenden Sie einen Mermaid-kompatiblen Renderer oder eine HTML-Seite mit Mermaid.js. Achten Sie darauf, keine zusätzliche globale CSS-Regel zu setzen, die die Schriftgröße verkleinert.
- Druck/PDF: Beim Export in PDF (A4) sicherstellen, dass Skalierung 100% oder „Größe anpassen“ ohne Verkleinerung ist.
